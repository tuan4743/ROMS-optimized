# 节点差异对性能影响验证（2026-08-10）

任务：验证不同节点（节点组/节点族）对 ROMS-CoSiNE 运行性能的影响，检查是否存在会扭曲优化判断的极端节点。

## 0. 一句话结论

**未发现系统性极端节点**：全部节点族（i17r1n/i17r2n/j01r2n/j04r2n/j05r2n）为同型号 Hygon C86 7185 32 核；同内容同二进制跨节点族 3 天全量波动 0.5–1.1%，ABBA 诊断重复性 0.2–1.1%，与 2% 决策门禁相比在可控范围。已知最大波动源是 /public 共享 I/O 争抢（+25–30%），是时间窗口性、非节点属性。现有 ABBA + 2% 门禁协议足以防护优化判断；跨作业异步全量对比的判读余量建议 ≥2%。

## 4. 极端情形：/public I/O 争抢（非节点属性）

- 同名 `sprint_O84` 3 天作业极差 29:39–38:35（30.1%）：
  - 08-08 02:53–10:37 窗口内 j01r2n[00-03] 三次 38:16–38:35（`118750169/118754089/118766756`）。
  - 队友 README 归因：共享 /public 磁盘 I/O 争抢（`sys` 20m vs 干净时 7m，墙钟 37–38m vs 29m22s）。
  - 同一节点组在 08-06 跑出 34:48（`118679795`）、08-08 干净期跑出 29:42（`118755216`）。
- **结论：极端慢不是节点固有属性，是争抢时间窗口属性**；同窗口内任何节点都会被拖慢。

## 5. 对优化判断的影响评估

| 判断类型 | 协议 | 噪声量级 | 判读 |
|---|---|---|---|
| 诊断 A/B（2% 门禁） | A1-B1-B2-A2 同分配 | 均值差噪声约 ±0.5%（B 对） | 稳健；B 需超 2% 才采纳，是噪声的 2–4 倍 |
| 诊断内首跑偏差 | — | A1 恒慢 1.4–4.7% | 若只用 A1 vs B1 单跑对比会产生假阴性/假阳性；均值协议已消除 |
| 全量异步跨作业对比 | 逐版本单跑 | 同内容 0.5–1.1%（节点+日期） | 版本差 ≥2% 可信；<2% 需同分配复测 |
| 计分候选确认 | 官方全量单跑 | +I/O 争抢可达 +30% | 建议计分前查争抢窗口（`sys` 计时）并记录节点组 |

案例检验：
- **S46 PGO 记录（1714.6 s）成立**：与 S42 比较在同族（i17r1n vs i17r2n）内进行，增益 ~2.0%，超跨族噪声（1.1%）→ 真实增益。
- **R2 biofast 全量 2033.079 s vs 冠军 2019.809 s（+0.657%）**：差值处于噪声区（跨节点组/跨日），方向性安全（未采纳 R2），但该 0.657% 数字本身不足以单独证明 R2 更慢。
- **S32 提交版 1762.5 s vs S32 前测 1753.9 s**：同节点组 0.49% 波动，提交成绩数字为口径所限。

## 6. 局限

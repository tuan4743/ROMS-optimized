## 3. 关键发现：yield 的争抢弹性

- **平静时段**：组合 −1.04%（both_B_faster=False）——各子项收益加和 ≈1%，低于 3% 门。
- **争抢时段**：−45.4%（A legs 8-9 分钟、B legs 4-5 分钟）——**yield 在争抢下保护墙钟**：busy-poll 轮询线程在争抢时烧 CPU（A user 142m vs 平静 33m）并与 I/O 争核；yield 让核 → real 大幅下降。B user 47m（比 A 的 142m 少 2/3）。
- **轨迹位级一致**：A1 vs B1 step 打印 diff=0（119093415）——组合数值安全（含 GLS precise 在该配置下未改变打印值）。

## 4. 判定与建议

- **平静收益 1% <3% 门 → 不达晋级标准**（按项目规则样本 ≥3% 双 B 快）。
- **但 yield 是零风险保险配置**（轨迹位级一致）：比赛时多队共享集群，争抢概率高——争抢时段可省 40%+。建议正式提交时启用 `mpi_yield_when_idle=1`（可加 `mpi_leave_pinned=1`；UCX_TLS=rc 与 HTMP1 贡献 ≈0 可不加）。
- GLS precise 单独无收益且理论 vali 风险 → 不采纳入组合。
- 组合测试 = 用户指定的"最后一次尝试"，结论明确：平静 1% + 争抢弹性 45% + 数值安全。

## 机制分析

1. **biology 被动性证实**：R2 全量 u=0.000052 与冠军完全相同 → CoSiNE 不耦合动力场，其浮点变化不影响 u；
   R2 ABBA 轨迹 5/5 SAME 同证。
2. **GLS 是 u 扰动唯一来源**：R3 的 B 轨迹与 fast2_2021 逐位相同，且 R3 只改 gls 的 div/speculation（无重关联）
   → 可见浮点变化全部由 gls 旗标产生；重关联（fast=2 独有）不贡献可见变化但贡献速度。
3. **速度-精度耦合**：GLS 速度 = fast=2 重关联（~4%），温和旗标速度 ≈ 0（R3−R2 ≈ +0.07%）；
   u 超限（0.000062 vs 0.000060）伴随任何 gls 旗标变化。分离不出安全配置。
4. **全量级样本反转**：R2 样本 +1.71% → 全量 −0.66%；hpcx211 样本 +2.30% → 全量 +0.03%。
   biology 的 fast=2 "加速"是 CPU 记账侧收益（perf 视角），墙钟侧被同步/负载平衡吸收或反转
   （与 2017 的 GLS 吸收家族同因：对象内 CPU 变快 ≠ 墙钟变快）。

## 与既有证据一致性

- 2017 侧 biology-only fast=2（Stage 108）：−2.82% STOP（墙钟更慢）→ 2021 侧 R2 全量 +0.66%（更慢）——方向一致：
  单侧编译变化在墙上永远不赚。
- fast=2 双对象在 2021 的 −4.54% 是唯一墙上赚的，但被 u 超限否定 → 与 gcc731 模式相同（速度换精度裕量失败）。

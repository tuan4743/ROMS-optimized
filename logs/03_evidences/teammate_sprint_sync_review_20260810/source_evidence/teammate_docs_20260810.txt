# ROMS_CoSiNE15 优化设计文档（S42 最终版 vs 无改动原代码）

> 生成时间：2026-08-09
> 最优版本：S42（3day 1750.1s = 29m10.1s，vali 26/26 全过）
> 对照基线：/public/home/fujiake/feng/mcc2026_final/ROMS_CoSiNE15（官方无改动源码）

## 一、设计思路总述

优化遵循三条铁律：
1. **位级中性优先**：除 biology 单项（单向耦合、不碰物理 u）外，所有改动不得改变浮点计算次序与数值语义，确保官方 vali 全过（S42 的 Dongsha u RMSE=5.2e-5，与基线位级一致）。
2. **热点驱动**：以 PROFILE 计时 + 采样为依据，只动真实热点（2D/3D/4D halo 交换、嵌套接触区、step3d_t/GLS/biology/2D 内核）。
3. **只换实现、不换算法**：物理方案、网格、时间步长、输出全部不变；改动集中在“通信实现方式”与“编译代码生成”两个层面。

总体收益链条：
- 编译层（-no-heap-arrays、AVX2/-no-fma、ifort2021、-ipo、-qopenmp 选择性并行）：约 -30% 起步
- 通信层（IN_PLACE 归约、批量打包、接触点稀疏、嵌套 p2p/单次 collect）：约 -15%
- 内核层（vdiff 系数复用、rho_eos 整例程并行）：约 -2%
- 综合：组委会 baseline 6606s → S42 1750.1s（3.77×）

## 二、原代码主要代码块与调用流程

### 2.1 程序骨架（ROMS 标准驱动）

```
ocean_control.F (op_ocean.h)
 ├─ initialize_parallel / inp_par / allocate
 ├─ main3d.F  STEP_LOOP（每个慢步）
 │   ├─ 阶段A 表面强迫/耦合（单线程）
 │   │   forcing → set_depth → set_massflux → rho_eos → bulk_flux
 │   │   → set_vbc → set_tides → lmd_vmix → bvf_mix → hmixing
 │   │   → omega → wvelocity → set_zeta → output
 │   ├─ 阶段B 3D 预测/校正（热点，选择性 OpenMP）
 │   │   rhs3d → my25_prestep → gls_prestep
 │   │   → step2d（barotropic 快速子步 ×30，串行）
 │   │   → set_depth → step3d_uv → omega → my25_corstep
 │   │   → gls_corstep → biology → sediment → step3d_t（tracer 预测+校正）
 │   └─ 阶段C 嵌套同步（每步多次）
 │       nesting(isection)：get_refine / put_refine / fine2coarse / bry_fluxes
 └─ 输出（def_*/wrt_*，master 进程写 NetCDF）
```

### 2.2 核心通信代码块（原版）

1. **halo 交换链**：exchange_2d/3d（本 tile 内部 halo 拷贝）→ mp_exchange2d/3d/4d
   （tile_neighbors 查邻居 rank → pack 到 sendW/E/S/N → MPI_IRECV+SEND+WAIT → unpack）。
   原版对 2D/3D/4D 分别调用，多字段时一次调用打包 Nvar 个场。
2. **嵌套接触区**：nesting.F 的 get_refine/put_refine/fine2coarse，
   原版用 mp_aggregate2d/3d（全网格 allgather）或 mp_sum（世界 allreduce）传递接触点数据；
   bry_fluxes 每层即时 mp_assemble（小消息世界归约，次数多）。
3. **数据收集/归约**：distribute.F 的 mp_collect/mp_assemblef_*/mp_reduce，
   原版用 Asend/Arecv 双临时数组 + RESHAPE 拷贝。

| O10 owner-packed fine2coarse | 全网格 allgather（AreaAvg 情形） | 各 rank 只算本地接触点均值→Packed→1 次 mp_sum | 通信量从全网格降为接触点数 |
| O10 sparse get_contact3d | 按 tile 全量取接触数据 | 稀疏计划：仅取实际接触点的 donor 数据（OCN_COMM_WORLD rank 编号映射） | 减少嵌套 3D 数据量 |

| O7 get_Vweights | 每步重算垂直插值权重 | 仅 composite 非重合网格需要时动态更新 | 初始化算一次，稳态跳过 |

## 六、结论

S42 以“位级中性 + 热点驱动 + 只换实现不换算法”为纲，通过
**编译器代码生成（ifort2021/AVX2/-no-fma/-ipo）、通信实现重构（IN_PLACE/批量打包/接触点稀疏/单次 collect）、
热点选择性 OpenMP、内核冗余消除（vdiff 系数复用、rho_eos 整例程并行）**四层手段，
在完全保持数值语义（vali 26/26、u=5.2e-5 位级一致）的前提下，将 3day 从组委会 6606s 优化至 1750.1s，加速 3.77×。

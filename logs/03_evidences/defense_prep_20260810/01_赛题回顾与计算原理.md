## 1. 赛题回顾

- 对象：ROMS-CoSiNE15，两个**双向嵌套**网格（SCS 粗网格 + Dongsha60 细网格，细网格空间/时间 5 倍加密）。
- 时间尺度：粗网格每前进一步，细网格前进 5 步；每个 3D 步内部做 `NDTFAST=30` 次 2D 正压快模积分（power-law 时间滤波使程序内显示 `nfast=42` 个加权阶段）。
- 计算内容：自由表面 ζ、2D/3D 流速、温盐、密度/压力梯度、潮汐/风应力/热通量/淡水通量、湿干、底摩擦、GLS 湍流、15 个 CoSiNE 生态变量、粗→细插值与细→粗反馈、NetCDF 输出。
- 物理基础：Boussinesq + 静力近似三维原始方程；示踪量输运方程 = 时间变化 + 水平/垂向平流 = 水平/垂向扩散 + 生态源汇。
- 网格：垂向 S 坐标（随地形变化），水平曲线正交 C 网格（ζ/示踪量在 RHO 点，u/v 在 U/V 点，交错存储）。
- 17 个示踪量 = 温度 + 盐度 + 15 生态变量。

## 2. 模式架构三要素

### 2.1 模式分裂（Barotropic-Baroclinic splitting）

ROMS 把自由表面/正压流（快，重力外波）与斜压流（慢）分离积分：

- **2D 快模** `step2d`：用短步长 `dtfast` 积分深度平均流 ubar/vbar 与 ζ，并做功率律时间滤波得到 `DU_avg1/DU_avg2/DV_avg1/DV_avg2/Zt_avg1`（快模时间平均，供 3D 步耦合使用）。
- **3D 慢模**：每步 `dt` 内，rhs3d（预测器）→ nfast 次 step2d（2D 快模）→ set_depth（用滤波后 ζ 更新层厚）→ step3d_uv（3D 动量校正器）→ step3d_t（示踪量校正器）。

### 2.2 时间层与积分格式

- 3D：预测-校正（predictor-corrector，LF-AM3 族，AM3 系数 23/12、3/2、1/4；首两步分别用 1/4、3/2·1/4 起步）。
- 2D：起步 Forward/Backward-Euler → 之后 Leap-frog predictor + Adams-Moulton corrector（系数 5/12、8/12、−1/12）。
- 状态量用 `nstp/nnew/nrhs`（3D）与 `kstp/knew/krhs/indx1`（2D）时间索引轮换；2D 还有 `nfast+1` 个辅助步专门完成滤波平均。
- 生态：内部趋向 backward-Euler 的迭代 `BioIter=1`。

### 2.3 C 网格与 S 坐标

- 水平通量 `Huon=Hz·u/n`、`Hvom=Hz·v/m` 在交错点计算；`omn=pm·pn` 是网格点面积倒数。
- 深度变量：`z_r`（RHO 点深度）、`z_w`（W 点深度）、`Hz`（层厚）、`D=ζ+h`（总水深）。
- `set_depth` 由滤波后 ζ 重建层厚（时变层厚，坐标随之移动）；`omega` 由质量通量散度自底向上积分连续方程得 S 坐标垂向速度 W。

## 3. main3d 主循环逐步流程（每 3D 步）

```text
[0] 时间索引推进 nstp/nnew/nrhs；iic+1；time+=dt
[1] get_data / set_data         读取强迫/边界 NetCDF 并做时间插值（OMP MASTER 单线程 IO）
[2] ini_zeta/set_depth          首步初始化 ζ 与层厚
[3] set_massflux + rho_eos + diag   计算质量通量、密度场、全局诊断量
[4] bulk_flux / bblm / set_vbc / set_tides   海气通量、底摩擦、垂向边界条件、潮汐
[5] omega + wvelocity           垂向速度（连续方程）与 w 诊断速度
[6] set_zeta + set_avg          置 ζ 为快模时间平均值；累计平均输出
[7] output                      延迟串行 NetCDF 输出（MASTER）
[8] nesting nputD               细网格从粗网格抽取数据做空间+时间插值填接触点
[9] rhs3d + gls_prestep          3D 方程右端项（预测器）+ GLS 预测
[10] LOOP_2D (nfast 次):
      step2d predictor（2D 快模预测）→ nesting n2dPS（2D 接触点）
      step2d corrector（2D 快模校正）→ nesting n2dCS
      （第 nfast+1 步仅做滤波收尾）
[11] nesting n2dfx + set_depth + nesting nzwgt
      2D 时间平均通量耦合；用新 ζ 重算层厚；嵌套区垂向插值权重
[12] step3d_uv                  3D 动量校正器（含与 2D 快模耦合）
      nesting n3duv（3D 动量接触点）
[13] omega + gls_corstep + biology   垂向速度更新、GLS 湍流校正、CoSiNE 生态源汇
[14] step3d_t                   17 个示踪量校正器（含垂向隐式扩散）
      nesting n3dTV（示踪量接触点）
[15] nesting n2way（双向反馈：细→粗用面积平均修正 2D/3D 粗网格场）
      nesting ngetD（粗网格抽取供体数据，供下步 nputD 时空插值）
[16] 回到 [0] 进入下一时间步
```

关键点：

- **嵌套同步节奏**：`ngetD`（粗网格步末抽数据）与 `nputD`（细网格步首插值）成对出现；细网格每 5 步（1 个粗步）只与粗网格交换一次，交换点由 `TwoWayCounter` 控制；`n2way` 每粗步末执行一次。
- 每段之后有 `!$OMP BARRIER`：OpenMP 线程间同步点；tile 循环顺序（正/逆）特意用于不可逆规约（set_avg）。
- 单线程串行段：get_data、output、nesting 各段（nzwgt/nmask 等标量段）。

## 4. 核心内核计算原理

### 4.1 step2d / step2d_LF_AM3.h — 2D 正压快模

推进变量：ζ、ubar、vbar。结构（每快模步，predictor 或 corrector）：

1. **快模时间滤波**：用功率律权重 `weight(1/2, iif, ng)` 累加 `Zt_avg1/DU_avg1/DU_avg2`（系数 5/12、8/12、−1/12 组合），消除快模高频信号。
2. **质量通量**：`DUon=ubar·0.5·on_u·(Drhs+Drhs(i-1))`（u 点深度平均通量）。
3. **自由表面方程**（ζ 推进）：
   - 预测器（LF）：`ζ_new = ζ(kstp) + 2·dtfast·pm·pn·(DUon 散度)`
   - 校正器（AM3）：`ζ_new = ζ(kstp) + pm·pn·[5/12·dt·rhs_now + 8/12·dt·rzeta(kstp) − 1/12·dt·rzeta(ptsk)]`
   - 滤波中间值 `zwrk`（2/5 与 3/5 混合）用于压力梯度。
4. **2D 动量 RHS**（rhs_ubar/rhs_vbar）：
   - 压力梯度：`0.5·g·on_u·[(h_i-1+h_i)·(gζ_{i-1}−gζ_i) + (gζ²_{i-1}−gζ²_i)]`，含 VAR_RHO_2D 密度修正项（gζSA、ρA 差）；
   - 水平平流：2 阶中心或 4 阶中心差分通量（UFx/UFe/VFx/VFe）；
   - 科氏项 `0.5·Drhs·f·(v 平均)`；
   - 曲率变换项（dndx/dmde）；谐波/双谐波黏性（visc2/visc4）；底摩擦与风应力（由 set_vbc/bblm 供给）。
5. **2D 动量推进**（深度加权通量形式）：
   `ubar_new = [ubar_old·Dstp + cff·rhs] / Dnew`（预测器）
   `ubar_new = [ubar_old·Dstp + cff·(5/12·rhs_now + 8/12·rubar(kstp) − 1/12·rubar(ptsk))] / Dnew`（校正器）
6. **湿干处理**：`wetdry_tile` 按水深阈值更新湿/干掩膜，动量乘 `umask_wet`。
7. 边界：`zetabc_tile`、`u2dbc/v2dbc`（2D 开边界）、`set_DUV_bc`；halo：`mp_exchange2d` 多次（每次 1–3 个变量）。

### 4.2 rhs3d — 3D 动量右端项（预测器）

输入 nrhs 时间层的 u/v/密度，输出 `ru/rv`（单位 m⁴/s²，已乘面积）：

1. 斜压压力梯度（prsgrd 提供，见 4.3）。
2. 水平黏性：谐波/双谐波通量形式（visc2/visc4，动量与示踪量两族）。
3. 体力化风应力/底应力：`sustr/bustr` 除以表层/底层厚度后加进 top/bottom 层 RHS（BODYFORCE 选项）。
4. 科氏项：`0.5·(Hz+Hz 邻点)·f·v` 形式。
5. 曲率变换项（曲线网格度量导数 dndx/dmde）。
6. 平流项：
   - 水平：2 阶/4 阶中心通量（UV_C2ADVECTION/UV_C4ADVECTION），`ru −= (UFx差 + UFe差)`；
   - 垂向：守恒抛物样条（UV_SADVECTION）——先对 u 构造样条导数 CF，再算半拉格朗日通量，无 CFL 限制。
7. 近岸辐射应力（NEARSHORE_MELLOR，未启用）。
8. 动量气候 nudging（未启用）。

### 4.3 prsgrd + rho_eos — 压力梯度与状态方程

- **rho_eos**：UNESCO EOS-80 型状态方程，逐点计算密度异常：
  - 1 大气压密度 `den1 = C0(T) + S·(C1(T) + √S·C2(T) + S·W00)`（C0..C2 为 T 的多项式，Horner 求值）；
  - 割线体积模量 `bulk = bulk0 − p·(bulk1 − p·bulk2)`；
  - 原位密度 `den = den1·bulk/(bulk + 0.1·p)`；温度下限 −2°C、盐度下限 0 PSU 截断。
  - 本项目队友 S42 将整个例程 j 循环 OpenMP 并行（PRIVATE 局部数组）——热对热有真实收益。
- **prsgrd**（本工程配置）：密度 Jacobian 型压力梯度（prsgrd32.h 等 2 点/3 点/4 点算法族），由 rho_eos 输出的 den 场计算水平压力梯度力。

### 4.4 pre_step3d — 示踪量与动量预测器（n+1/2 中间层）

示踪量部分（t(…,3,itrc)）——通量形式：

1. 水平平流通量：本配置默认 4 阶中心差分（TS_C4HADVECTION 族：FX = Huon·t 差商、4 阶修正项、掩膜）；备选 2 阶中心、MPDATA 一阶上游、3 阶上游、4 阶 Akima。
2. **人工连续性方程**：用 Ω（S 坐标垂向速度场）的散度构造人工垂向速度，保证每个 tracer 的有限体积相容性（质量守恒）。
3. 垂向平流 + 垂向扩散：垂向扩散隐式（三对角，Akt 系数），温度含非局部输运（KPP LMD_SKPP 相关项）与太阳辐射穿透项（SOLAR_SOURCE：`swdk` 由 `lmd_swfrac` 算）。
4. 输出 `t(…,3,itrc)` = n+1/2 层中间示踪量，供校正器 MPDATA 反扩散与 biology 使用。

动量部分（u/v 的 n+1/2 中间值）：`u(…,3) = u(nnew) + 0.25·dt·(pm+pm)·(pn+pn)·ru`（后续校正器用）。

### 4.5 step3d_uv — 3D 动量校正器

1. 用 rhs3d 的 ru/rv 按 AM3 系数推进：`u(nnew) += cff·ru`（cff = 23/48·dt·面积，首步 1/4，次步 3/2 倍）。
2. 垂向黏性隐式求解：标准三对角（`−λ·dt·Akv/Hz` 型系数）或 SPLINES_VVISC 抛物样条三对角（LU 分解 + 前代 + 回代）。
3. **与 2D 快模耦合**：把深度平均的 ubar/vbar（快模时间平均 DU_avg）嵌入 3D 流速——先算 3D 深度平均偏差，再用校正后的深度平均流量重算质量通量 `Huon=Hz·u/n`（"barotropic correction"）。
4. 边界：`u3dbc/v3dbc`（3D 开边界、梯度/辐射组合），`mp_exchange3d`（u/v 各一次，每 k 层 Nghost 点）。

### 4.6 step3d_t — 示踪量校正器

1. 水平平流通量重算（与 pre_step3d 相同方案族），MPDATA 模式下加**反扩散修正**（anti-diffusive velocity + 修正通量，抑制数值耗散）。
2. 垂向平流通量（显式）+ 垂向扩散隐式三对角（Akt 系数，λ 加权）。
3. 惰性示踪量/年龄（INERT_TRACER）处理。
4. 边界条件：`t3dbc`（示踪量开边界）+ nudging + `rmask` 掩膜。
5. **整块 4D halo 交换**：`mp_exchange4d(t(:,:,:,nnew,:))` 一次交换全部 NT=17 个示踪量——本项目最大的 4D 通信热点。
6. 生态/沉降已在 biology 中并入 t(nnew)（乘 Hz 转输运单位）。

### 4.7 gls_prestep / gls_corstep — GLS 湍流两方程

- **prestep**：湍动能 tke 与通用长度尺度 ψ 的水平扩散、边界条件准备。
- **corstep**：
  1. 剪切频率平方 `shear2`（u/v 垂向梯度）与浮力频率平方 `buoy2`（密度垂向梯度，稳定时为正）。
  2. 产生项：`P = gls_c1·shear2·(Akv−Akv_bak) − gls_c3·buoy2·(Akt−Akt_bak)`（c3 随稳定/不稳定切换，负产生并入耗散）。
  3. 耗散项 BCK/BCP（含壁函数 wall_fac，Lmy25 时抛物线壁函数修正）。
  4. 隐式推进 tke/gls（三对角，含垂直对流项）。
  5. 由 tke、ψ 与通用长度尺度公式 `L = C⁰·ψᵖᵒʷ·tkeᵖᵒʷ` 计算 `Akv/Akt/Akk/Akp`（GLS 系列：k-ε/k-ω/k-kl 可切换）。
  6. 本工程 gls_corstep 有 OpenMP 热点并行（队友与 O33 均包含）。

### 4.8 biology / bio_UMAINE15.h — CoSiNE 生态

15 变量索引（NAT=温盐 2 + 15 生态，NBT=15）：NO3、NH4、SiOH4、小浮游植物 Sphy、硅藻 Lphy、微型浮游动物 Szoo、中型浮游动物 Lzoo、含氮碎屑 SDet、生物硅 opal、PO4、O₂、TIC、碱度、Chl1、Chl2（CARBON+OXYGEN 全开时）。

每 (i,k) 点、每迭代（BioIter=1）的源汇项计算顺序：

1. **光场**：`PARsur = PARfrac·srflx·ρ₀·Cp`；衰减系数 `kd = AK1 + (Sphy+Lphy)·AK2`；自上而下指数衰减 `PIO(k) = PIO(k+1)·exp(−kd·Hz)`，层平均 PAR；深度适应因子 ADPT（随深度线性降到零）+ 浅水修正 cffik。
2. **温度依赖**：Q10 = exp(0.069·(T−25))，乘到各速率。
3. **生长速率**（小浮游植物为例）：
   - 氮：`uno3s1 = pnh4s1·NO3/(akno3s1·cens1)`，`unh4s1 = NH4/(aknh4s1·cens1)`（铵抑制 pnh4s1 = exp(−pis1·NH4)，Liebig min 合成）；
   - 磷 `upo4s1`、碳 `uco2s1` 类似 Michaelis-Menten；
   - 光限制 `alts1 = (1−exp(−PAR·ADPT/parsats1))·cffik`；
   - 生长率 `grows1 = min(氮+铵, 磷, 碳)·光`（然后按比例拆分 NO3/NH4 吸收）。
   - 硅藻多一个硅酸盐限制项（SiOH 与 ak 半饱和，红场比 ro5 等偏好系数）。
4. **摄食**：微型/中型浮游动物按偏好系数（ro5/ro6/ro7）捕食小浮游植物/硅藻/碎屑/中型动物，Michaelis-Menten 型（β1·P/(akz1+P)），摄食效率 bgamma1/2。
5. **死亡/排泄/再生/硝化**：bgamma0/3/4/5 死亡率、reg1/2 排泄、bgamma7 硝化（NH4→NO3，受 OXR 氧限制）、反硝化（OXYGEN 分支）。
6. **O₂/CO₂ 海气交换**：`CO2_flux` 子程序——Schmidt 数、风速参数化（kw660）、pCO2 溶解度、O₂ 交换（`pCO2s` 由 TIC/碱度/PO4/Si 迭代求）。
7. **沉降**：SDet/opal/Lphy/Chl1/Chl2 用固定沉降速度 Wbio；**WENO 抛物线重构 + 半拉格朗日无 CFL 通量**（bR/bL 界面值、单调限制、ksource 出发格搜索）。
8. **回写**：`t(nnew,indx) = max(t(nnew,indx) + (Bio−Bio_bak)·Hz, 1e-5)`（浓度×层厚回输运单位，保正）。

### 4.9 nesting.F — 双向嵌套

数据结构：`Rcontact/Ucontact/Vcontact`（每个接触区 cr 的点表 Idg/Jdg 与权重），`REFINED`（双滚动时间记录：`RollingTime/RollingIndex` 存粗网格 t 与 t+dt 两快照供时空插值）。`isection` 参数驱动分段处理：

- `ngetD`（粗网格步末）：get_contact2d/3d 抽取 ζ/ubar/vbar/DU_avg2/17 示踪量/u/v 到 REFINED。**每个 rank 只填自己 tile 内的点（owner-compute），然后 `mp_assemble` 全局收集+广播**（本项目优化：全量 Allgather → 稀疏 Allgatherv，见 distribute）。
- `nputD`（细网格步首）：put_refine 对接触点做空间插值（4 角双线性）+ 时间插值（t、t+dt 两快照）；先 ζ（独立并行区）后其余。
- `n2dPS/n2dCS`：2D 快模预测/校正步的接触点交换（CompositeGrid 用，本工程为 RefinedGrid 所以走 get_refine 路径）。
- `nzwgt`：z_weights 由新深度算垂向插值权重（细网格层在粗网格层内的位置）。
- `n2way`（双向反馈，每粗步末）：`correct_tracer`（细网格边界通量修正粗网格示踪量）+ `fine2coarse`（2D：r2dvar 面积平均回代；3D：r3dvar 面积平均回代，先 set_depth 更新粗网格层厚）。
- `nmflx`：质量守恒诊断。

### 4.10 distribute.F — MPI 规约/收集

- `mp_assemble*`（1d/2d/3d）：接触点数据全局收集——本地填充 Aspv 哨兵值 → **Allgather 到全数组 → 取非哨兵值**。项目优化将全量 Allgather 改为稀疏 owner 模式（只通信有数据的 tile，v22 基线）。
- `mp_bcastf/i/l/s_*`：标量/数组广播（项目优化：分层 Bcast——leader communicator 节点间广播 + 节点内共享内存广播，v24a，Bcast 时间 12.37%→1.81%）。
- `mp_boundary/mp_reduce_scatter` 等：边界与规约（`distribute_owner_reduce_scatter3d_hier.F` 为分层 ReduceScatter）。

### 4.11 mp_exchange.F — halo 交换

- `mp_exchange2d/3d/4d`（+ bry 边界族）：标准模式 = 打包 EW/NS 边界列（含 ghost）到栈缓冲 → **先 mpi_irecv 后阻塞 mpi_send**（EW 对、NS 对，tag 1-4 防死锁）→ mpi_wait → 解包。
- 2d/3d/4d 分别交换 1-4 个变量（打包按变量顺序排列在同一个 send 缓冲）。
- 项目经验（赛题文档 + 实测）：`Irecv→Send→Wait` 是 UCX/HPCX 最优模式；Isend+Waitall、Sendrecv、持久请求、双缓冲重叠全部实测退步（v24b −50%、v25 −5%、v26 −59%、v28 −100%）。

## 5. 并行结构总览

| 层次 | 机制 | 规模 |
|---|---|---|
| MPI | 每 grid 的 tile 分给 rank；64 ranks（8×8 剖分/网格） | 4 节点 64 ranks × 2 线程 |
| OpenMP | tile 循环 `DO tile=first,last` + 内核内 j 循环并行（rho_eos/biology/gls 等） | 每 rank 2 线程 |
| 通信 | 邻居 halo（EW/NS）、接触点 assemble、Bcast、Allreduce（diag） | 2D/3D/4D halo 每次交换 |
| IO | get_data/output 单线程 MASTER | NetCDF |

- 每段计算后用 `!$OMP BARRIER` 同步 → OpenMP 同步点与 MPI halo 是主要等待来源。
- 负载不均衡来源：陆海掩膜、湿干、嵌套接触区（粗网格 6 个中心 tile 独占全部 contact 供给点，细网格西边界环最重）——快 rank 在 MPI_Wait 等慢 rank。
- 嵌套同步：细网格每 5 步与粗网格交换一次（TwoWayCounter），ngetD/nputD 成对。

## 6. 与性能优化结论的对应（答辩要点）

- 初始瓶颈 = 双向嵌套大数组规约（Allgather） + RESHAPE/临时数组内存复制清零 + MPI 等待 → 对应优化：稀疏 assemble、分层 Bcast、去临时数组。
- 编译器主导（S32 线）：ifort2021.3.0 + `-march=core-avx2 -no-fma`（no-fma 钉住 FP 行为，保证 u=5.2e-5 位级）+ 全局 `-ipo`；PGO（-prof-use）在 precise 下 u 保持 0.000052。
- 通信重构全部关闭：交换重构、非阻塞化、双缓冲、rankmap——UCX 流水线模式不可破坏；rankmap 方形块仅 +0.79% 噪声。
- 计算内核优化仅剩：rho_eos 整例程 OMP（S42，真收益）、step3d_t vdiff 系数复用（S38，−0.67%）、t3dmix 小数组压栈（负向，页缺失）。
- 线程化失败教训：4 节点 128 ranks 反而更慢（带宽受限）；`ompk` 串行路径（step2d 耦合、嵌套插值、打包）不随线程缩放。

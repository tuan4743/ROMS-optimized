## 8. 运行 ROMS_CoSiNE15 需要的文件夹及作用

以官方 `perf_sandbox` 结构为准（当前最优版本保留了运行所需子集）：

| 文件夹 | 作用 |
|---|---|
| ROMS/ | 模型核心源码。含 Adjoint（伴随模型）、Bin（构建脚本 sfmakedepend/cpp_clean 等）、Drivers（nl_ocean.h 等驱动头）、External（标准输入文件 .in 与生物参数文件）、Functionals（解析函数 ana_*.h）、Include（全局头文件 cppdefs.h/globaldefs.h 等）、Modules（各 mod_*.F 数据模块）、Nonlinear（非线性内核 step2d/step3d_t/nesting 等）、Obsolete（废弃代码）、Programs（主程序辅助）、Representer/SeaIce/Tangent（表示子空间/海冰/切线性）、Utility（工具例程 mp_exchange/distribute 等）、Version（版本） |
| Master/ | 主控程序：ocean_control.F（入口）、master.F、roms_import/export.F（ESMF/MCT 耦合接口） |
| Compilers/ | 平台编译器宏文件（Linux-ifort.mk / Linux-gfortran.mk），决定 FFLAGS/LDFLAGS 与按文件编译选项 |
| Projects/ | 工程配置目录（bye24 工程），编译时通过 PROJECT 宏引用 |
| Data/ | 模型标准数据（Data/ROMS），含默认网格/掩码等参考数据 |
| Atmosphere/ | 大气驱动耦合目录（COAMPS、WRF 数据接口） |
| User/ | 用户自定义覆盖目录（Biology/External/Functionals/Include），可覆盖默认实现 |
| Inputfiles/ | 实际运行输入数据（网格、初值、边界、强迫场），运行时通过软链指向共享目录 /public/home/fujiake/Inputfiles |
| Build/ | 构建中间产物（*.o、*.f90、*.mod、lib*.a），make 自动生成 |
| Lib/ | 预编译库目录（perf_sandbox 附带） |

构建产物为 `oceanM` 可执行文件；提交脚本 `sub_local.sh` 负责环境加载、rankfile 绑定、NTIMES 注入、运行与 vali。
